# Project Context

## Project Name
Live Location Tracking System

## Problem Statement
**Organization:** National Security Guard (NSG), Ministry of Home Affairs, India  
**Year:** 2024  
**Domain:** Miscellaneous  
**Category:** Software

## Problem Background

The National Security Guard operates in Close Quarters Battle (CQB) environments where personnel operate inside complex buildings such as hotels, hospitals, metro stations and other multi-storey structures.

The smallest operational unit is the House Intervention Team (HIT). The Task Force Commander needs to understand the locations of personnel operating across different floors and basements.

Traditional GPS/GSM-based tracking systems primarily provide 2D location information and cannot reliably identify the floor at which a person is operating indoors.

## Requirements from Problem Statement

1. Track personnel and House Intervention Teams.
2. Identify their floor or basement level.
3. Visualize their positions in 3D.
4. Integrate location information with existing 3D building models.
5. Provide a centralized monitoring interface.

## Our Project Objective

We are developing an **academic software prototype** that demonstrates indoor floor-level location visualization using simulated device data.

The system will:
- Display simulated personnel/device positions in a multi-storey 3D building.
- Update positions in real time.
- Use a generic demonstration building (created by us).
- Use synthetic location data (no tracking hardware).

## Important Disclaimers

- This is an academic prototype, not an operational NSG deployment.
- Simulated tracking does not demonstrate real-world indoor positioning accuracy.
- No real personnel information or sensitive building plans are used.
- The system is intended for academic and controlled demonstration purposes.
